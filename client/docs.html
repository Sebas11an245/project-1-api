Pokédex API Documentation

This API provides access to Pokémon data stored in a local JSON dataset. All endpoints return JSON by default and support the appropriate HTTP methods.

GET /api/pokemon

Supported Methods: GET, HEAD

Query Parameters (optional)

  • type (string) – filter Pokémon by type
  • generation (number) – filter by generation
  • limit (number) – limit number of results
  • name (string) – partial name search

Returns

JSON object containing count and list of Pokémon.

Example

GET /api/pokemon?type=fire&limit=5

GET /api/pokemon/:id

Supported Methods: GET, HEAD

URL Parameters

  • id (number, required) – Pokémon ID

Returns

Single Pokémon object in JSON format.

Example

GET /api/pokemon/25

GET /api/pokemon/type/:type

Supported Methods: GET, HEAD

URL Parameters

  • type (string, required) – Pokémon type

Returns

Array of Pokémon that match the given type.

Example

GET /api/pokemon/type/water

GET /api/stats

Supported Methods: GET, HEAD

Query Parameters (optional)

  • minAttack (number)
  • minDefense (number)
  • minSpeed (number)

Returns

List of Pokémon that match the stat filters.

Example

GET /api/stats?minAttack=100

POST /api/pokemon

Supported Methods: POST

Body Parameters

  • name (string, required)
  • type (array or string, required)
  • generation (number, required)
  • stats (object, required)

Returns

The newly created Pokémon object.

Example

POST /api/pokemon
{
  "name": "Testmon",
  "type": ["Fire"],
  "generation": 1,
  "stats": { "attack": 50, "defense": 40, "speed": 60 }
}

POST /api/pokemon/:id

Supported Methods: POST

URL Parameters

  • id (number, required)

Body Parameters (optional)

  • name (string)
  • type (array or string)
  • generation (number)
  • stats (object)

Returns

The updated Pokémon object.

Example

POST /api/pokemon/25
{
  "name": "Updated Pikachu"
}
